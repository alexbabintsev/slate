Slate

Welcome to Slate

One Chrome window for every project. Three quick steps and you're set

  1. 1

    Pin Slate to the toolbar

    Chrome tucks new extensions behind the puzzle icon. Click it, then the pin next to Slate, so your projects are one click away

    → Slate

    Pinned, you're all set

  2. 2

    Create your first project

    Name it after something you work on. Slate opens a fresh window for it and saves its tabs as you go

    Already have a window full of tabs for it? Open Slate in that window and click the folder with a plus to save it as a project

  3. 3

    Switch in one click

    Click the Slate icon and pick a project: Slate opens its window or brings it to the front

    The letter on the icon shows which project the window belongs to. Close a project window any time, its tabs stay saved

Rename, reorder and recolor projects, or back them up, in the side panel

Prefer the terminal? Open and close projects with the optional slate command

How to set it up

Everything stays in this browser: no account, no tracking, no servers
